# 📊 Electronic Sales Data Analysis

## 📌 Project Overview

This project analyzes electronic sales data using Python to discover sales trends, product performance, and customer purchasing patterns.

The project follows an Exploratory Data Analysis (EDA) approach, including data cleaning, data preparation, analysis, and visualization.

---

## 🎯 Objectives

- Analyze electronic sales data.
- Clean and prepare the dataset.
- Explore sales patterns and trends.
- Identify top-performing products.
- Analyze customer purchasing behavior.
- Discover meaningful relationships and patterns.
- Generate data-driven business insights.

---

## 🛠️ Tools & Technologies

- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub

---

## 🔍 Analysis Process

### 1. Data Understanding
- Dataset structure and dimensions
- Data types
- Missing values
- Duplicate records
- Initial data exploration

### 2. Data Cleaning
- Handling missing values
- Checking duplicates
- Converting data types
- Preparing date columns
- Ensuring data consistency

### 3. Exploratory Data Analysis

The analysis explores:

- Sales performance
- Product performance
- Customer behavior
- Sales trends over time
- Product/category patterns
- Distribution of sales

### 4. Data Visualization

The project uses several visualizations, including:

- Bar Charts
- Histograms
- Box Plots
- Line Charts
- Count Plots
- Distribution Plots


## 📈 Key Insights

The analysis provides insights into:

- Top-performing products
- Sales trends over time
- Customer purchasing patterns
- Product/category performance
- Sales distribution

Detailed findings and visualizations are available in the Jupyter Notebook.
